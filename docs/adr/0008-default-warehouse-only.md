# 0008. Продают только с основного склада

Дата: 2026-09-03. Решение владельца.

## Контекст

У организации может быть несколько складов, и напрашивалось показывать агенту
сумму остатков по всем и продавать с любого. Но отгрузка идёт с одного —
основного; остальные — приёмка, хранение, перемещения.

## Решение

Заказ резервирует и списывает только с основного склада (`isDefault`). Экраны
продажи показывают остаток основного склада, а не сумму по всем: сумма
обещала бы товар, которого на отгрузке нет.

## Последствия

Перемещение на основной склад — отдельная операция через дверь остатка
(ADR 0001). Отчёты по складам считают каждый склад отдельно.
