# 0010. Стражи и храповики: каждый ломается нарочно

Дата: 2026-09-09. Требование владельца.

## Контекст

Тесты с подделкой базы проверяют арифметику стенда, а не поведение продукта.
Ряд правил («остаток пишет только дверь», «цветов числом не больше N», «каждая
ручка кем-то зовётся») невозможно выразить обычным тестом — они про форму кода.

## Решение

Два вида проверок. Страж читает исходники как текст и требует, чтобы правило
стояло на месте (например, проверка лимита — до записи в базу). Храповик
считает число нарушений и не даёт ему вырасти; опускается руками, когда
нарушений стало меньше. Каждый новый страж ломается нарочно один раз: без этого
неизвестно, ловит ли он что-нибудь (страж, окно которого «ещё N знаков»
цепляло соседний запрос, был найден именно так).

Поведение денег и склада проверяется на настоящей MySQL (`api/__tests__/real-db`,
джоба `real-db` в CI).

## Последствия

Правки крупных файлов тянут за собой правки стражей — для этого есть
`__tests__/helpers/*-source.ts`. Зелёный прогон без базы не доказывает
поведение базы; это делает `real-db`.
