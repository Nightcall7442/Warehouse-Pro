# Записи о решениях (ADR)

Одна запись — одно решение, которое нельзя вывести из кода: почему так, что
рассматривалось, чем платим. Записи не правятся задним числом; отменённое
решение получает новую запись со ссылкой на старую.

Формат: Контекст → Решение → Последствия. Дата — когда решение принято.
