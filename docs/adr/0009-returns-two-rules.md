# 0009. Возвраты считаются двумя правилами

Дата: 2026-09-10.

## Контекст

Возврат влияет на две разные величины: выручку периода и долг магазина по
заказу. Одна формула на обе давала расхождения: возврат прошлого месяца
уменьшал выручку текущего, а долг по заказу считался без учёта возвращённого.

## Решение

Выручка — по дате возврата в периоде (возврат уменьшает выручку того месяца,
когда он проведён). Долг магазина — по заказу: возвращённое по документу
вычитается из того, что магазин должен за этот заказ, независимо от периода.
Смешивать правила нельзя; обе проверяются на настоящей базе
(`real-db/revenue-returns`, `real-db/shop-debt-rules`).

Проведённый возврат решает, куда идёт товар: на склад (`restock`) или в
списание (`write_off`); брак, просрочка и порча по умолчанию списываются.

## Последствия

Отчёт за период и карточка магазина могут показывать разные суммы возвратов
за один месяц — это правильно, они отвечают на разные вопросы.
